# Code of Conduct

## Expected behavior

Treat everyone with respect. Be constructive, assume good intent, and keep feedback focused on
ideas and work. Harassment, discrimination, threats, personal attacks, sexualized language, and
doxxing are not allowed.

## Scope

This applies in issues, pull requests, discussions, releases, and other project spaces.

## Enforcement

Maintainers may remove content, reject contributions, or restrict participation when this code is
violated. Decisions will consider context, impact, and repeated behavior.

## Report concerns

For a confidential report, open a [private GitHub Security Advisory](https://github.com/coderj001/openGym/security/advisories/new) and begin the summary with `Code of Conduct report`.
Do not disclose incident details publicly. Maintainers aim to acknowledge reports within seven
days and handle them as confidentially as practical.
