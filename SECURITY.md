# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit a private report through
[GitHub Security Advisories](https://github.com/coderj001/openGym/security/advisories/new)
with reproduction steps, impact, and any suggested mitigation.

Maintainers must enable GitHub's **Private vulnerability reporting** before public release so
reports can be submitted by people without repository write access.

## Scope

This policy covers the mobile application, release workflow, and repository configuration.
